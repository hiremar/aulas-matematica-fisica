O que é uma função quadrática

É toda função que pode ser escrita como

f(x) = ax² + bx + c,  com a ≠ 0

a, b e c são números reais chamados coeficientes. O "a" não pode ser zero: sem o x², a função vira uma reta (função do 1º grau). O gráfico de toda função quadrática é uma curva chamada parábola.

Achando a, b e c (cuidado com a ordem e com os sinais!)
  • f(x) = 2x² − 3x + 1 → a = 2, b = −3, c = 1
  • f(x) = −x² + 4 → a = −1, b = 0, c = 4 (não tem x: b = 0)
  • f(x) = 5x − x² → a = −1, b = 5, c = 0 (o a é quem acompanha o x², esteja onde estiver)

Quanto maior o valor de |a|, mais "fechada" fica a parábola.

2. Onde corta o eixo y: o c

No eixo y, x vale zero. Então f(0) = a·0² + b·0 + c = c. A parábola sempre corta o eixo y no ponto (0, c).

3. As raízes (zeros): fórmula de Bhaskara

Raízes são os valores de x que fazem f(x) = 0, ou seja, onde a parábola corta o eixo x. Primeiro calculamos o discriminante (delta):

Δ = b² − 4ac

E depois:

x = −b ± √Δ2a

Δ > 0Δ = 0Δ < 0
duas raízes reais diferentes
(corta o eixo x em 2 pontos)		uma raiz real (dupla)
(só encosta no eixo x)		nenhuma raiz real
(não toca o eixo x)
Exemplo: raízes de f(x) = x² − 5x + 6
  1. a = 1, b = −5, c = 6
  2. Δ = (−5)² − 4·1·6 = 25 − 24 = 1
  3. x = −(−5) ± √12·1 = 5 ± 12
  4. x₁ = 62 = 3  e  x₂ = 42 = 2

Erro clássico: (−5)² = +25. Quando b é negativo, use parênteses!

4. O vértice: o ponto de máximo ou de mínimo

A parábola é simétrica: o vértice fica bem no meio das raízes. As coordenadas são:

xv = −b2a     yv = −Δ4a  (ou yv = f(xv))

Exemplo: vértice de f(x) = x² − 5x + 6
  1. xv = −(−5)2·1 = 2,5 (bem no meio de 2 e 3!)
  2. yv = −14·1 = −0,25
  3. Como a > 0, o vértice é um ponto de mínimo: o menor valor de f é −0,25.

5. Atalho: soma e produto

Se x₁ e x₂ são as raízes:

x₁ + x₂ = −ba     x₁ · x₂ = ca

Quando a = 1, dá para achar as raízes "de cabeça": em x² − 5x + 6, procure dois números que somam 5 e multiplicam 6: são 2 e 3.

6. Onde isso aparece

Bola chutada para cima: h(t) = −5t² + 20t (h em metros, t em segundos)
  1. a = −5 < 0: a parábola tem ponto de máximo (a altura máxima).
  2. Instante do topo: tv = −202·(−5) = 2 s
  3. Altura máxima: h(2) = −5·4 + 20·2 = 20 m
  4. Volta ao chão quando h = 0: −5t² + 20t = 0 ⟹ t(−5t + 20) = 0 ⟹ t = 0 ou t = 4 s.
Cercado de área máxima: com 40 m de tela, qual o maior retângulo possível?
  1. Se um lado é x, o outro é 20 − x (meio perímetro menos x).
  2. Área: A(x) = x(20 − x) = −x² + 20x.
  3. xv = −202·(−1) = 10: um quadrado de 10 m × 10 m, com área de 100 m².

🏀 Arremesso parabólico

A bola sai da origem (0, 0) e segue a parábola f(x) = ax² + bx. Ajuste os coeficientes para a bola passar pela cesta! No nível 1 você só mexe no b; a partir do nível 2, no a e no b.

Nível: 1Cestas: 0Pontos: 0Tentativas nesta cesta: 0

Dica: f(x) = ax² + bx vale 0 em x = 0 e em x = −b/a. A bola "cai" de volta no chão nesse segundo ponto!

💡 Estudo do sinal

Às vezes a pergunta não é "quanto vale f(x)?", mas "para quais x a função é positiva?". Basta olhar a parábola em relação ao eixo x:

Para f(x) = x² − 2x − 3 (raízes −1 e 3, boca para cima):

  • f(x) > 0 (acima do eixo) quando x < −1 ou x > 3;
  • f(x) = 0 quando x = −1 ou x = 3;
  • f(x) < 0 (abaixo do eixo) quando −1 < x < 3.

Regra de bolso: "fora das raízes, o sinal de a; entre as raízes, o sinal contrário".
